# Barinella

Esta skill acumula conhecimentos sobre a empresa Barinella. Deve ser lida sempre que a empresa fizer parte do contexto da conversa.

## BIS2

A Barinella utiliza o BIS2 como sistema de automação comercial para controlar o cadastro de produtos, entradas de notas, geração de SPED, emissão de cupons de venda (NFC-e) e outras atividades comerciais.

Quando o contexto envolver a Barinella e atividades realizadas no BIS2, leia também a skill `bis2-knowledge`.
